# Tarn

**Tarn** is an experimental, compiled systems language: Rust-style ownership and borrowing checked at compile time (no GC, no lifetime annotations) with small, Go-like syntax, native code via Cranelift, and a pnpm-inspired package manager (hash-verified lockfile, immutable releases, no install hooks).

🌐 [Website](https://tarn-lng.github.io/website/) · 📦 [Registry](https://tarn-lng.github.io/registry/) · 💬 [Discussions](https://github.com/tarn-lng/tarn/discussions) · 🟢 [Good first issues](https://github.com/search?q=org%3Atarn-lng+is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22&type=issues)

> Tarn is young (Linux x86_64 / ARM64) and moves fast. Feedback, bug reports and PRs are very welcome, in English or Spanish.

## Get involved

Pick an issue labeled `good first issue`, comment on it so a maintainer can assign it to you, and read the [contributing guide](https://github.com/tarn-lng/.github/blob/main/CONTRIBUTING.md). Questions and ideas go to [Discussions](https://github.com/tarn-lng/tarn/discussions).
